# Secure Login Automation Tester

# Overview
This project is an automated testing script built with C# and Selenium WebDriver. It serves as a proof-of-concept for automated UI testing and quality assurance, simulating user interactions to validate secure authentication mechanisms. 

The script automates the process of navigating to a login interface, injecting credentials, and programmatically verifying the system's response (Assertion) to ensure successful access to secure areas.

# Tech Stack
* Language: C# (.NET)
* Automation Framework: Selenium WebDriver
* Browser Driver: Microsoft Edge (EdgeDriver)

# Key Features
* Automated Navigation: Programmatic control of the browser session.
* Element Localization: Locating web elements using DOM IDs and CSS Selectors.
* Interaction Simulation: Automated keystrokes and form submissions.
* Result Assertion: Reading dynamic UI elements to validate the expected authentication outcome.

# How to Run
1. Clone the repository to your local machine.
2. Open the project in Visual Studio.
3. Ensure the Selenium.WebDriver and Selenium.WebDriver.MSEdgeDriver NuGet packages are restored.
4. Build and run the Console Application. The Edge browser will launch automatically to execute the test scenario.
